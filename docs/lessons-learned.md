# Lessons Learned

## Project Overview

The Azure Cost Visibility Dashboard was designed to help organizations monitor Azure spending, receive budget alerts, investigate cost increases, and improve governance through tagging and automation.

---

## Technical Lessons Learned

### Azure Cost Management

I learned how Azure tracks spending and provides visibility into cloud resource consumption.

Skills gained:

- Cost Analysis
- Budget Management
- Spending Forecasting
- Cost Investigation

---

### Azure Governance

I learned how resource tags improve ownership tracking and cost allocation.

Tags implemented:

- Project
- Environment
- Owner
- Department
- CostCenter

---

### Azure Logic Apps

I learned how to automate cloud operations using serverless workflows.

Skills gained:

- Event-driven automation
- HTTP triggers
- Email notifications
- Workflow design

---

### Azure Monitor and Action Groups

I learned how Azure alerts are generated and routed to stakeholders.

Skills gained:

- Alert management
- Notification routing
- Monitoring fundamentals

---

### Azure Resource Graph

I learned how to query Azure resources using Kusto Query Language (KQL).

Skills gained:

- Resource inventory reporting
- Governance reporting
- Tag validation

---

### Azure Workbooks

I learned how to create operational dashboards that provide visibility into cloud environments.

Skills gained:

- Dashboard design
- Visualization
- Operational reporting

---

## Operational Lessons Learned

### Documentation Is Critical

A cloud solution is not complete without:

- Architecture documentation
- Runbooks
- Troubleshooting guides
- Operational procedures

---

### Cost Optimization Is Continuous

Cloud cost management requires ongoing monitoring and investigation.

Organizations must continuously:

- Review budgets
- Investigate alerts
- Optimize resources
- Improve governance

---

### Troubleshooting Is a Core Cloud Skill

Several implementation challenges required investigation and problem solving.

Examples:

- VM quota limitations
- Workbook configuration issues
- Resource Graph query errors
- Cost reporting delays

---

## Business Lessons Learned

Cloud engineering is not only about deploying resources.

Cloud engineers must also:

- Understand business requirements
- Monitor costs
- Build automation
- Improve governance
- Communicate findings

---

## Final Outcome

This project demonstrates practical experience with:

- Azure Cost Management
- Monitoring and Alerting
- Cloud Governance
- Automation
- Documentation
- Cloud Operations

and provides a repeatable framework for helping organizations improve visibility into Azure cloud spending.
